# Floating resize hit targets and captured Escape

The first integrated PR #16 host run passed 75 of 77 cases. Its resize case never acquired frame capture at the thin right border. Its Escape case did not cancel: after mouse release the source x changed from 20 to 35 and the revision advanced. These are failures, not a merge-ready result. All original 129 cases passed, but two of the eight new floating cases exposed missing behavior.

Floating content groups are drawn as siblings above their frame. Internal resize grips can therefore be covered by content, and the one-pixel remaining boundary is unreliable under pointer/device-pixel rounding. DockSite now retains eight border-only hit targets above each resizable floating host's groups and splitters. They include four inner logical units and two outer units of tolerance, clipped by the site; they do not place a full-window input overlay over the editor. Hits invoke the existing WindowControl movement engine, capabilities, magnetism and revision-checked commit path. A small internal visual-bounds notification keeps these targets aligned during pointer, keyboard, layout and cancellation changes. No new controls are allocated on each bounds update.

Pointer capture does not transfer keyboard focus. The nested sample's Reset toolbar remains the focus owner when its non-focusable caption begins a drag. DockSite now installs a temporary root-preview Escape handler only for a currently captured site gesture. It consumes only Escape while that site still owns capture. Release, cancellation, unload, manager replacement and stale source rejection remove it. Other keys and other sites remain unaffected. Splitters and auto-hide resizing use the same capture-scoped cancellation.

The existing guide-retention case now explicitly observes Escape cancellation while the mouse is still held, before releasing it. It still checks unchanged layout/revision, retained guide identities and no remaining preview. This strengthens the assertion rather than treating mouse release as a substitute for cancellation. The original resize pointer coordinate and its geometry/identity assertions remain unchanged. The stationary-click case additionally requires the temporary keyboard scope to be removed.

All 137 product cases, 23 model suites, package consumers, glyph-ink tests and the separate 100-cycle focus gate remain required at the corrected head. The change fixes hosted input layering and cancellation; it does not implement native OS windows, full live floating-content reflow, or complete vendor accessibility/pixel parity.
